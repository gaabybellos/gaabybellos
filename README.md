## What I Do

I work at the intersection of quality and engineering. My focus is not only writing tests, but designing the infrastructure that makes testing useful, traceable, and sustainable.

- **Test architecture:** Playwright and Cypress frameworks, 4-layer Page Object Model, parallel execution, resilient selectors, tags, reports, and multi-environment strategy.
- **Backend validation:** REST APIs, payloads, contracts, authentication, SQL, logs, async workers, events, and data consistency.
- **CI/CD integration:** GitHub Actions, Azure DevOps, Jenkins, Docker, PR quality gates, release protection, and suite stability monitoring.
- **AI-powered QA:** Multi-agent workflows for discovery, test planning, test generation, risk analysis, bug audit, technical review, and test healing using Claude Code, OpenAI Codex, Cursor, Google Antigravity, and MCP.
- **QA strategy:** Risk-based planning, reverse engineering, traceability, test data governance, regression strategy, smoke strategy, and quality culture.

## My Approach

Quality is not a gate at the end of the pipeline. It is part of how software is designed, reviewed, shipped, and maintained.

My pattern is simple:

1. Understand the system through discovery and reverse engineering.
2. Identify critical risks, business rules, data flows, and integration points.
3. Design traceable requirements, test cases, specs, and automation strategy.
4. Build scalable test infrastructure with CI/CD feedback.
5. Keep quality visible to engineering and invisible as friction to delivery.
